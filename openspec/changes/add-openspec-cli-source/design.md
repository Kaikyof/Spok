## Context

`ExecutableLocator` уже ищет `claude` и `git` с учётом урезанного PATH при
запуске из Finder; `CommandLog` показывает выполненные команды в панели
запуска. См. proposal.md.

## Goals / Non-Goals

Goals: валидация и точная схема при наличии CLI; сигнал о расхождении
парсера. Non-Goals: запуск `openspec archive`, `new change` из приложения
— это команды спеки, их запускает агентная сессия.

## Decisions

- **Расширение, а не часть ядра**: улика — не файл спеки, а бинарь на
  машине; природа нехватки — `runtime`. В «Расширениях» видно «CLI не
  найден» с командой установки.
- **Только `--json` команды, только чтение.** `validate --all --json`,
  `status --change <id> --json`, `list --json`, `schema which <name> --json`.
  Таймаут 15 с, вывод в `CommandLog`.
- **Схема из CLI — первый источник** в `SchemaResolver`, когда расширение
  активно; результат кэшируется на слепок.
- **Расхождение счёта задач** — сравнение `completedTasks/totalTasks` из
  `list --json` с нашим парсером; при разнице — предупреждение у change'а
  «счёт задач отличается от `openspec list`» (это сигнал багрепорта, не
  ошибка пользователя).
- **Версия CLI** записывается в разбор спеки; при версии ниже 1.13 —
  предупреждение, расширение работает.

## Risks / Trade-offs

- [Формат JSON меняется между версиями upstream] → разбор терпимый к
  лишним полям; неизвестная форма — «недоступно с причиной».
- [CLI медленный на большой спеке] → вызовы параллельно с чтением файлов,
  результат приходит вторым обновлением.
