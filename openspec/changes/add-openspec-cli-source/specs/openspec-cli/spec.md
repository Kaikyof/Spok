## Purpose

Использование установленного CLI оригинального OpenSpec как
необязательного источника: валидация change'ей, точная схема, сверка
счёта задач.

## ADDED Requirements

### Requirement: Без CLI ничего не меняется

Приложение SHALL работать без установленного `openspec`; отсутствие бинаря
показывается только в разделе «Расширения» с природой нехватки `runtime`.

#### Scenario: Машина без CLI
- **WHEN** `openspec` не найден в PATH и типовых каталогах
- **THEN** экраны те же, что до этого change'а; в «Расширениях» строка
  «CLI OpenSpec не найден» с командой установки

### Requirement: Валидация change'ей

При наличии CLI приложение SHALL показывать результат `openspec validate`
для каждого change'а: «валидно» или число замечаний с их текстом.

#### Scenario: Change без дельт и без skip_specs
- **WHEN** у change'а нет `specs/**` и нет `skip_specs: true`
- **THEN** у change'а бейдж «1 замечание» с текстом валидатора

### Requirement: Схема из CLI предпочтительнее копии

При наличии CLI приложение SHALL разрешать схему через `openspec schema
which --json` и использовать встроенную копию только при ошибке CLI.

#### Scenario: Пользовательская схема
- **WHEN** схема лежит в `~/.local/share/openspec/schemas/`
- **THEN** источник схемы в разборе — «user», путь — из ответа CLI

### Requirement: Сверка счёта задач

Приложение SHALL сравнивать свой счёт задач с `openspec list --json` и
показывать предупреждение при расхождении.

#### Scenario: Парсер отстал от upstream
- **WHEN** `openspec list` даёт 5/7, а приложение насчитало 4/7
- **THEN** у change'а предупреждение «счёт задач отличается от openspec»
