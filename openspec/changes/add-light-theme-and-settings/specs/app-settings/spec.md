## Purpose

Настройки приложения, доступные из интерфейса: тема, язык, агентный
инструмент, модели, поведение обновления, каталог данных.

## ADDED Requirements

### Requirement: Экран настроек приложения

Приложение SHALL иметь экран настроек с темой, языком, агентным
инструментом и путём к нему, списком моделей, режимом `git pull` при
обновлении и каталогом данных; изменения сохраняются в файл конфига и
применяются без перезапуска.

#### Scenario: Смена языка
- **WHEN** человек выбирает русский на английской системе
- **THEN** интерфейс переключается на русский сразу, выбор сохранён

### Requirement: Файл конфига остаётся источником

Экран SHALL читать и писать тот же файл конфига, что и раньше; ключи,
которых экран не знает, SHALL сохраняться без изменений.

#### Scenario: Ручной ключ в файле
- **WHEN** в файле есть ключ, добавленный вручную, и человек меняет тему
  на экране
- **THEN** после сохранения ключ на месте
