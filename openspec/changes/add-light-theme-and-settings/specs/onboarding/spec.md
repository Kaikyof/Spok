## Purpose

Первый запуск приложения и подключение каталога, в котором OpenSpec ещё
нет.

## ADDED Requirements

### Requirement: Каталог без OpenSpec

При выборе каталога без `openspec/` приложение SHALL объяснить это и
предложить запустить `openspec init`, если CLI найден, либо показать
ссылку на инструкцию upstream.

#### Scenario: CLI установлен
- **WHEN** выбран каталог репозитория без `openspec/`, `openspec` найден
- **THEN** экран предлагает «Инициализировать OpenSpec» с предпросмотром
  команды; после подтверждения запускает её в панели запуска и открывает
  проект

#### Scenario: CLI не установлен
- **WHEN** `openspec` не найден
- **THEN** экран показывает команду установки и ссылку на документацию
  upstream, кнопки инициализации нет

### Requirement: Пример проекта

Первый запуск SHALL предлагать открыть пример проекта на оригинальном
OpenSpec, чтобы увидеть приложение с данными.

#### Scenario: Открыть пример
- **WHEN** человек нажимает «Открыть пример»
- **THEN** пример копируется в каталог данных и открывается как проект

### Requirement: Проверка инструментов

Первый запуск SHALL показывать, найдены ли `claude` (или другой агент) и
`openspec`, с подсказкой по установке для ненайденных.

#### Scenario: Нет агента
- **WHEN** ни один агентный инструмент не найден
- **THEN** на экране первого запуска строка «агентный инструмент не
  найден» со ссылками на установку
