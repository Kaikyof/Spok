## Why

Этап 10 плана, интерфейсная часть. У приложения только тёмная тема
(`main.dart:59`), настройки живут в файле `.env` каталога приложения,
который человек со стороны не найдёт, первый запуск без спеки — пустое
поле URL вместо онбординга, доступность не проверялась. Для инструмента
одной команды это терпимо; для открытого — нет.

## What Changes

- Светлая тема: вторая палитра `AppColors`, проверка цветов стадий и
  статусов; режим системный по умолчанию, переключатель в настройках.
- Экран настроек приложения: тема, язык, агентный CLI и путь, список
  моделей, `git pull` при обновлении, каталог данных; файл конфига
  остаётся хранилищем.
- Первый запуск: «в этом каталоге нет OpenSpec — запустить `openspec init`?»
  при найденном CLI, ссылка на upstream, пример проекта; проверка `claude`
  и `openspec` с подсказкой по установке.
- Доступность: семантика у таблиц и точек статуса, обход экранов с
  клавиатуры, масштаб шрифта, контраст обеих тем, guideline-тесты.

## Capabilities

### New Capabilities
- `theme`: светлая и тёмная темы, системный режим.
- `app-settings`: настройки приложения в интерфейсе.
- `onboarding`: первый запуск и проект без OpenSpec.
- `accessibility`: доступность интерфейса.

### Modified Capabilities
- нет.

## Impact

- `lib/core/theme/`, `lib/core/resources/app_colors.dart`, `main.dart`,
  новый `settings_screen.dart`, `setup_screen.dart`, `AppConfigSource`,
  ключевые экраны (семантика), тесты.
- Для avtoto и avelacom: тёмная тема остаётся при тёмной системе; настройки
  из файла подхватываются.
- Зависит от `split-core-and-extensions` (локали в настройках) и
  `add-agent-cli-port` (выбор агента в настройках).
