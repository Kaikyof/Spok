## Purpose

Как приложение находит файл задач change'а, считает отметки и определяет
единицу работы, когда стеков и трекера у спеки нет.

## ADDED Requirements

### Requirement: Файл задач из apply.tracks

Если схема не объявляет артефактов `tasks-<stack>`, приложение SHALL брать
файл задач из `apply.tracks` схемы (или из артефакта с id `tasks`) и
создавать для change'а одну единицу работы независимо от наличия данных
трекера.

#### Scenario: Проект на схеме spec-driven
- **WHEN** у change'а есть `tasks.md` с тремя отметками, две закрыты, и нет
  `redmine.yaml`
- **THEN** у change'а одна единица работы с прогрессом 2/3

#### Scenario: Спека со стеками
- **WHEN** схема объявляет `tasks-ios` и `tasks-android`
- **THEN** единицы работы — стеки `ios` и `android`, как до этого change'а

### Requirement: Отметки задач считаются по правилам upstream

Приложение SHALL считать задачей строку с маркером списка (`-`, `*`, `+`,
`N.`, `N)`), возможно с отступом, и одним символом в квадратных скобках;
`x` и `X` означают «сделано», любой другой символ или пробел — «не
сделано»; строка, где за скобкой идёт `(` или `[`, задачей не считается;
номер вида `N.N` необязателен.

#### Scenario: Список через звёздочку и вложенность
- **WHEN** `tasks.md` содержит `* [X] Первая`, `  - [ ] 1.2 Вторая`,
  `- [~] Третья`, `- [Документ](./doc.md)`
- **THEN** задач три: первая сделана, вторая и третья нет; ссылка не
  учтена

#### Scenario: Файл с переводами строк CRLF
- **WHEN** `tasks.md` сохранён с `\r\n`
- **THEN** все задачи посчитаны, текст задач без `\r`
