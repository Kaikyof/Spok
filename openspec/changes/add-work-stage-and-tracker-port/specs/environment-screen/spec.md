## Purpose

Экран «Окружение» как набор разделов, каждый из которых показывается по
улике в спеке: ключи по `.env.example`, репозитории по `workspace.yaml`,
внешние системы по ключам адресов.

## ADDED Requirements

### Requirement: Внешние системы из ключей примера

Раздел «внешние системы» SHALL строиться из ключей `.env.example` вида
`<SYSTEM>_URL`, а не из зашитого списка; при отсутствии таких ключей раздел
не показывается.

#### Scenario: Только Redmine
- **WHEN** в `.env.example` есть `REDMINE_URL`, но нет `GITLAB_URL` и
  `MATTERMOST_URL`
- **THEN** в разделе одна строка — Redmine; предупреждений «GitLab не
  настроен», «Mattermost не настроен» нет

#### Scenario: Примера нет
- **WHEN** в спеке нет `.env.example`
- **THEN** раздел систем и раздел ключей не показываются

### Requirement: Раздел ключей только при примере

Раздел ключей и форма их заполнения SHALL показываться только при наличии
`.env.example`; без него требования «ключ не заполнен у меня» не возникают.

#### Scenario: Проект без ключей
- **WHEN** открыт проект на оригинальном OpenSpec
- **THEN** ни один экран не предлагает «Заполнить ключи»
