## Purpose

Языки интерфейса приложения, выбор локали и согласованность строк между
локалями и пакетами.

## ADDED Requirements

### Requirement: Английский по умолчанию, русский по системе

Приложение SHALL поддерживать английский и русский; язык выбирается по
системной локали, при неподдерживаемой — английский.

#### Scenario: Английская система
- **WHEN** системная локаль `en-US`
- **THEN** интерфейс на английском, даты и относительное время в
  английском формате

#### Scenario: Русская система
- **WHEN** системная локаль `ru-RU`
- **THEN** интерфейс на русском, как до этого change'а

### Requirement: Паритет строк между локалями

Каждая локаль каждого пакета SHALL содержать тот же набор ключей, что и
остальные локали пакета; расхождение — ошибка теста.

#### Scenario: Ключ добавлен только в одну локаль
- **WHEN** в `app_ru.arb` ядра появился ключ без пары в `app_en.arb`
- **THEN** тест паритета завершается ошибкой с именем ключа

### Requirement: Строки расширения живут в расширении

Тексты, которые называют конкретную систему, SHALL находиться в
локализации пакета соответствующего расширения; строки ядра называют
систему через подстановку.

#### Scenario: Полоса о ключе трекера
- **WHEN** активен адаптер Redmine и ключ пуст
- **THEN** текст полосы взят из локализации ядра с подстановкой имени
  «Redmine» из адаптера

### Requirement: Тексты спеки не переводятся

Описания команд из frontmatter, вывод агента и содержимое документов SHALL
показываться на языке спеки без перевода.

#### Scenario: Английская команда в русском интерфейсе
- **WHEN** описание `/opsx:propose` на английском, интерфейс на русском
- **THEN** в палитре описание показано по-английски
