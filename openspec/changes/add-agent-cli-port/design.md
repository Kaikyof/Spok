## Context

`AgentCliSource.start` собирает аргументы `claude -p … --output-format
stream-json --verbose --model … --effort … [--permission-mode] [--resume]`,
парсит строки JSON в `AgentEvent`, хранит id сессии для `--resume`.
`invocation.ts` upstream объясняет формы вызова по инструментам. См.
proposal.md и план, 4.7.1.

## Goals / Non-Goals

Goals: сессия работает с любым из четырёх агентов; палитра подставляет
верную форму вызова. Non-Goals: интерактивные разрешения внутри сессии,
«агент ждёт решения» (открытый вопрос сводного документа).

## Decisions

- **Порт `AgentCli`**: `id`, `name`, `locate()`, `supportsResume`,
  `supportsModel`, `supportsEffort`, `supportsPermissionMode`,
  `invocationStyle` (`namespaced` · `flat` · `skill` с префиксом),
  `start(prompt, options) → Stream<AgentEvent>`. Адаптеры объявляют, что
  умеют; строка параметров под полем ввода показывает только поддерживаемое.
- **События** — общий `AgentEvent` (текст, инструмент, ошибка, итог);
  каждый адаптер парсит свой формат: Claude `stream-json`, Codex `exec
  --json` (JSONL), Gemini `--output-format json`, OpenCode `run --format
  json`. Неизвестное событие — сырой текст в ленту, не ошибка.
- **Выбор агента по проекту**: по умолчанию первый найденный из тех, для
  которых проект инициализирован (каталоги), при отсутствии — первый
  найденный на машине; сохраняется в настройках проекта рядом с моделью.
- **Форма вызова** — по агенту и по тому, какие файлы есть: у Claude
  `commands/opsx/<id>.md` → `/opsx:<id>`; у Cursor `opsx-<id>.md` →
  `/opsx-<id>`; у Codex только скиллы → `$openspec-<skill>`. Таблица
  соответствия команд и скиллов — из дедупа этапа 3.
- **Без headless-режима** (Cursor) — кнопка «Скопировать команду»: строка
  собирается, копируется, сессия не запускается.
- **Список моделей** по агенту — из конфига (`SESSION_MODELS_<agent>`),
  пополняется вводом, как сейчас.

## Risks / Trade-offs

- [Форматы JSON агентов меняются] → адаптер терпим к неизвестным полям;
  тесты на образцах вывода каждой версии.
- [Разрешения: у каждого агента свой флаг] → адаптер маппит общий
  «расширенный доступ» в свой флаг или сообщает, что не поддерживает.

## Migration Plan

Настройка модели и effort по проекту сохраняется; добавляется агент.
